# Глоссарий

| Термин             | Значение                                                                                      |
| ------------------ | --------------------------------------------------------------------------------------------- |
| сессия             | пара access/refresh токенов одного входа; у пользователя их несколько (устройства)            |
| refresh            | обмен refresh-токена на новую пару; refresh-токен ротируется                                  |
| 2FA, второй фактор | второй пароль после основного; вход требует `twoFactorToken` из ответа на первый шаг          |
| passkey            | вход по WebAuthn-ключу устройства                                                             |
| право (permission) | строка вида `ресурс:действие` с wildcard-иерархией (`user:*`, `*`)                            |
| область (scope)    | «все» или «свои» (`<право>:own`) — над любыми сущностями или только где пользователь владелец |
| владелец           | пользователь, связанный с сущностью (автор, ответственный); список решает вызывающий код      |
| роль               | именованный набор прав; системные роли не удаляются; роль admin даёт всё                      |
| суперпользователь  | пользователь с `*` или ролью admin                                                            |
| каталог прав       | список прав с подписями и группами с сервера                                                  |
| комната            | серверная подписка Socket.IO на поток событий (`users`, `roles`, `api-keys`, `audit`)         |
| аудит, журнал      | события действий пользователей; «мой журнал» — свои, админский — все                          |
| API-ключ           | ключ доступа к API; секрет показывается один раз при создании                                 |
| холдер             | объект асинхронного состояния запроса (`shared/lib/holders`)                                  |
| VM-хук             | `use<Name>VM` — хук сценария страницы/фичи, отдаёт данные и действия UI                       |
| слайс, сегмент     | единицы FSD — [architecture/fsd-layers](../20-architecture/fsd-layers.md)                     |
