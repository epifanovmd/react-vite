# Неиспользуемый код — заготовки, не удалять без команды

## Ситуация

При аудите модулей найден неиспользуемый код: зарегистрированные, но не
инжектируемые сервисы (`IMediaService`, `IWebRTCService`), неиспользуемые экспорты
`shared/lib/hooks` и `shared/lib/utils`, неиспользуемые методы VM. Пользователь
указал: это заготовки на будущее, удалять не нужно. Правило YAGNI в
`clean-code.md` говорит обратное: «Удалить ненужный код лучше, чем хранить «на
будущее»».

## Предложение

В `docs/40-principles/clean-code.md`, раздел YAGNI, заменить последнее предложение:

> Новый код «на будущее» не пишется. Существующий неиспользуемый код (сервисы,
> экспорты, методы) может быть заготовкой: он не удаляется в рамках рефакторинга
> или задачи без явной команды пользователя — находка сообщается в отчёте.

В `docs/10-process/review.md`, чек-лист «Код», добавить:

> - [ ] Неиспользуемый существующий код не удалён без команды пользователя.

## Обоснование

Указание вида «никогда» повторится при каждом рефакторинге и ревью; без правки
документ толкает агента удалять заготовки.
