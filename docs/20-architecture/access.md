# Доступ и права

Право — строка с иерархией: wildcard покрывает вложенные права. У действия может быть
область «все / свои»: вариант `<право>:own` разрешает действие только над
сущностями, где пользователь среди владельцев. Право на все покрывает право на свои,
не наоборот.

- **Грамматика прав** (сопоставление, wildcard, область) — чистые функции в
  `shared/lib`: она общая для нескольких сущностей одного слоя. Сущности строят
  поверх неё проверки доступа и редактирование набора прав.
- **Стор текущего пользователя** — единственная точка проверки в UI:

  | Что                                                 | Как                             |
  | --------------------------------------------------- | ------------------------------- |
  | есть ли право                                       | `can`                           |
  | область права: все / свои / нет                     | `scope`                         |
  | можно ли действие над конкретной сущностью          | `canOn` по списку её владельцев |
  | отпечаток прав — ключ мемоизации производных от них | `accessKey`                     |

  Кто владелец (автор, ответственный) — решает вызывающий код; стор сверяет текущего
  пользователя со списком.

- **Экран**: гейт маршрута и пункт навигации — при праве хотя бы на свои. Комната
  списка в реальном времени — только при праве на все; с правом на свои события
  приходят адресно.
- **Действия в списках и таблицах** решаются по строке, а не по экрану.
- **Редактор прав** задаёт действие с областью уровнем «Нет / Свои / Все» и
  шаблонами групп; действие шире просмотра поднимает просмотр, понижение просмотра
  опускает действия.
- **Источник истины — сервер**: клиентская проверка скрывает недоступное, но не
  заменяет серверную.
