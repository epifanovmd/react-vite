# auth-layout

Обёртка страниц периметра `_auth` (вход, регистрация, сброс пароля): фон, логотип,
название приложения и футер с годом.

## Public API

| Экспорт      | Что                                        |
| ------------ | ------------------------------------------ |
| `AuthLayout` | Лейаут; проп `children` — содержимое формы |

## Устройство

- Подключается в `src/app/routes/_auth.tsx` вокруг `<Outlet />`; там же `beforeLoad`
  редиректит авторизованного пользователя на `/`.
- Колонка `max-w-md` по центру экрана, без состояния.

## Зависимости

- `@shared/config/env` — `APP_NAME`.

## Gotcha

- Название приложения берётся из `APP_NAME` (`VITE_APP_NAME`), как в логотипе шапки, —
  не захардкожено (тест `AuthLayout.test.tsx`).
